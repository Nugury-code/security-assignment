🔓 2. 공개 정보 (3가지)

  • 웹페이지 구조를 이루는 HTML 마크업 소스 코드

  • 공개 정보와 비공개 정보를 구분한 보안 점검표 문서

🔒 3. 비공개 정보 (3가지)

  • 개인 식별이 가능한 정보 (작성자의 이름, 전화번호, 이메일 주소 등)
